A web-based platform that allows users to publish property advertisements while enabling potential customers to browse, search, and find their desired houses easily.

⸻

✨ Features
	•	📝 Post property advertisements with detailed information
	•	🔍 Browse and search available properties
	•	🏡 View complete property details including pricing and specifications
	•	📱 Fully responsive and user-friendly interface
	•	⚡ Fast data loading using AJAX
	•	🗄️ Structured property data storage using MySQL

⸻

🛠️ Technologies Used
	•	Frontend: HTML5, CSS3, Bootstrap, JavaScript
	•	Backend: PHP
	•	Database: MySQL
	•	Communication: AJAX

⸻

🚀 Getting Started

📌 Prerequisites

Make sure you have installed:
	•	PHP
	•	MySQL
	•	Web Server (XAMPP, WAMP, or similar)

⸻

📥 Installation
	1.	Clone the repository: git clone https://github.com/benyamin-mashkoorzadeh/real-estate.git

  2.	Move the project to your web server directory (e.g., htdocs in XAMPP).
	3.	Import the database:

	•	Open phpMyAdmin
	•	Create a new database
	•	Import the provided .sql file

	4.	Configure database connection:

Update database credentials in the configuration file.

⸻

▶️ Run the Project

Start your local server and open:  http://localhost/your-project-folder
